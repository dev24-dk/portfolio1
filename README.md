# Creative IT Portfolio

A complete responsive portfolio website built with:

- HTML5
- CSS3
- JavaScript
- Responsive design
- Accessibility features
- Dark/light mode
- Mobile navigation
- Scroll reveal animations
- Contact form validation

## Files

- `index.html` — website structure
- `style.css` — complete styling and responsive layout
- `script.js` — interactions and form validation
- `assets/` — project illustration images

## Before submitting

Open `index.html` and replace:

1. `Your Name` with your actual name.
2. `yourname@example.com` with your email.
3. `github.com/yourusername` with your GitHub profile.
4. Update project descriptions if you want to show your actual projects.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Commit the files.
4. Go to Settings → Pages.
5. Select the main branch as the deployment source.
6. Save.
7. Open the generated GitHub Pages URL.

Example:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
